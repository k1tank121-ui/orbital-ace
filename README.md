# ORBITAL ACE · 오비탈 에이스 — 하늘에서 우주까지

적 편대를 격파하고 대기권을 돌파해, 궤도 위의 모선을 파괴하는 3D 비행 슈팅 게임입니다. 브라우저에서 바로 플레이할 수 있습니다.

## ▶ 바로 플레이

**https://k1tank121-ui.github.io/orbital-ace/**

PC 브라우저(Chrome · Edge 권장)에서는 키보드 · 마우스로, 휴대폰 · 태블릿에서는 터치로 플레이합니다. 휴대폰은 가로로 들고 하는 것을 권장합니다.

## 조작법 (PC)

| 동작 | 키 |
|---|---|
| 기체 조향 | W A S D 또는 방향키 (옵션: 마우스 조향) |
| 기관포 사격 | Space · J · 마우스 왼쪽 |
| 유도 미사일 | F · K · 마우스 오른쪽 |
| 부스트 | Shift |
| 감속 | X |
| 배럴 롤 | Q / E |
| 일시정지 | P 또는 Esc |
| 음소거 | M |
| 광원 효과 켜기/끄기 | B |

## 조작법 (휴대폰 · 태블릿)

| 동작 | 터치 |
|---|---|
| 기체 조향 | 화면 왼쪽 절반을 드래그 (손가락을 댄 자리에 가상 스틱이 나타남) |
| 기관포 사격 | 사격 버튼 — 적을 조준하면 자동 사격 (타이틀에서 끌 수 있음) |
| 유도 미사일 | 미사일 버튼 (빨갛게 깜박이면 록온 완료) |
| 부스트 | 부스트 버튼을 누르고 있기 (테두리 링이 남은 양) |
| 배럴 롤 | ↶ / ↷ 버튼 |
| 일시정지 · 음소거 | 오른쪽 위 Ⅱ · ♪ 버튼 |

터치 화면 기기에서는 자동으로 터치 조작이 켜집니다. PC에서 터치 화면을 미리 보려면 주소 뒤에 `?touch=1`을 붙이세요.

## 로컬에서 실행

```bash
python -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 구성

lib/         three.js와 후처리(블룸) 모듈
